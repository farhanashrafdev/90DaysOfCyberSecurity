# ૯૦ દિવસીય સાયબર સેક્યુરીટી અધ્યયન યોજના.

૯૦ દિવસ ની સાયબર સીક્યુરિટી ચેલેન્જ માં આપનું સ્વાગત છે.
આ રિપોઝીટરી (સંગ્રહ) સાયબર સિક્યોરિટીમાં મજબૂત પાયો તૈયાર કરવામાં મદદ કરવા માટે વ્યવસ્થિત રીતે આયોજિત, ૯૦ દિવસનો સેલ્ફ-પેસ્ડ (પોતાની ગતિએ શીખી શકાય તેવો) સ્ટડી પ્લાન પ્રદાન કરે છે. ભલે તમે આ ક્ષેત્રમાં શરૂઆત કરવા માંગતા નવશિક્ષિત હોવ અથવા તમારી કુશળતાને વધુ ધારદાર બનાવવા માંગતા વ્યાવસાયિક હોવ, આ રોડમેપ તમને કાળજીપૂર્વક પસંદ કરેલા અસંખ્ય સંસાધનો, પ્રેક્ટિકલ કાર્યો અને શીખવા માટેની સામગ્રી પ્રદાન કરે છે.

દૈનિક મોડ્યુલ્સ આવશ્યક અને અદ્યતન વિષયો આવરી લે છે, જેમાં નીચેનાનો સમાવેશ થાય છે:
- નેટવર્કિંગ ફંડામેન્ટલ્સ (Network+)
- સુરક્ષા સિદ્ધાંતો (Security+)
- લિનક્સ બેસિક્સ અને શેલ સ્ક્રિપ્ટીંગ
- સુરક્ષા કાર્યો માટે પાયથોન પ્રોગ્રામિંગ
- ટ્રાફિક વિશ્લેષણ અને પેકેટ ઇન્સ્પેક્શન
- ગિટ (Git) સાથે વર્ઝન કંટ્રોલ
- ELK સ્ટેકનો ઉપયોગ કરીને SIEM ટૂલ્સ અને લોગ વિશ્લેષણ
- GCP, AWS અને Azure સાથે ક્લાઉડ સુરક્ષા
- પેનિટ્રેશન ટેસ્ટિંગ અને એથિકલ હેકિંગ
- નોકરી મેળવવી: વન-પેજ રેઝ્યૂમે અને કરિયર-ઓપ્સ સાથે AI-સહાયિત જોબ-સર્ચ પાઇપલાઇન

દરેક દિવસ તમને ટ્રેક પર રાખવા માટે કાર્યક્ષમ કાર્યો (actionable tasks), ટ્યુટોરિયલ્સ અને વાંચન સામગ્રી સાથે ડિઝાઇન કરવામાં આવ્યો છે. સંસાધનોની સંપૂર્ણ સૂચિ માટે, [`learn.md`](../../learn.md) નો સંદર્ભ લો.

## 🎯 ધ્યેયો અને પ્રેક્ષકો

### 📌 ધ્યેયો

આ ૯૦ દિવસની યોજનાનો પ્રાથમિક ઉદ્દેશ્ય શીખનારાઓને નીચે મુજબ મદદ કરવાનો છે:

- કોર સાયબર સિક્યોરિટી ખ્યાલો અને પ્રથાઓમાં મજબૂત પાયો બનાવવો.
- દૈનિક કસરતો અને વાસ્તવિક દુનિયાના સાધનો દ્વારા પ્રેક્ટિકલ અનુભવ મેળવવો.
- CompTIA Network+ અને Security+ જેવા પ્રમાણપત્રો માટે જરૂરી તકનીકી કુશળતા વિકસાવવી.
- નેટવર્ક સિક્યોરિટી, સિસ્ટમ હાર્ડનિંગ, ક્લાઉડ સિક્યોરિટી, સ્ક્રિપ્ટીંગ અને એથિકલ હેકિંગ સહિતના મુખ્ય ડોમેન્સનું અન્વેષણ કરવું.
- લાંબા ગાળાના રીટેન્શન અને વિકાસને સમર્થન આપવા માટે 90 દિવસ દરમિયાન સતત શીખવાની ટેવ વિકસાવવી.

આ સફરના અંત સુધીમાં, તમને વિવિધ સાયબર સિક્યોરિટી ટૂલ્સ, ખ્યાલો અને તકનીકો નેવિગેટ કરવામાંત્મવિશ્વાસ અનુભવાવો જોઈએ.

### 👥 લક્ષિત પ્રેક્ષકો

આ રિપોઝીટરી નીચેના લોકો માટે આદર્શ છે:

- **સાયબર સિક્યોરિટી ક્ષેત્રે કારકિર્દી બનાવવા ઈચ્છતા લોકો** જેઓ એન્ટ્રી-લેવલની નોકરીઓ અથવા પ્રમાણપત્રોની તૈયારી કરી રહ્યા છે.
- **IT પ્રોફેશનલ્સ** જેઓ સિક્યોરિટી-ફોકસ કેરિયરમાં ટ્રાન્ઝિશન કરી રહ્યા છે.
- **વિદ્યાર્થીઓ** જેઓ કોમ્પ્યુટર સાયન્સ, ઇન્ફોર્મેશન સિસ્ટમ્સ અથવા નેટવર્ક એન્જિનિયરિંગનો અભ્યાસ કરી રહ્યા છે.
- **સ્વયં-શિક્ષકો (Self-learners)** જેઓ એક રચનાત્મક અને વ્યાપક અભ્યાસ યોજના શોધી રહ્યા છે.
- **ડેવલપર્સ અને ડેવઓપ્સ (DevOps) એન્જિનિયર્સ** જે સુરક્ષિત ઇન્ફ્રાસ્ટ્રક્ચર અને જોખમ શોધ (threat detection) ને વધુ સારી રીતે સમજવા માગે છે.
- **કોઈપણ ઉત્સુક વ્યક્તિ** જે વાસ્તવિક દુનિયાના વાતાવરણમાં સાયબર સુરક્ષા કેવી રીતે કામ કરે છે તેના વિશે જાણવા માંગે છે.

કોઈ અગાઉના અનુભવની જરૂર નથી, જો કે કોમ્પ્યુટર, નેટવર્ક અથવા પ્રોગ્રામિંગથી પ્રાથમિક પરિચય મદદરૂપ થશે.

## 🚀 અહીંથી શરૂ કરો

આ પ્લાન માટે નવા છો? પહેલા આ વાંચો, પછી [Day 1](#day-1-7-network) પર જાઓ.

- **સમયનું આયોજન:** દરરોજ ૧ થી ૨ કલાક ધ્યાન કેન્દ્રિત કરવાનું લક્ષ્ય રાખો. દિવસના નંબરો એક માર્ગદર્શિકા છે, અંતિમ તારીખ નથી; કોઈ વિષય પર વધુ સમય વિતાવવો ઠીક છે.
- **ક્રમનું પાલન કરો:** દિવસ ૧ થી ૨૮ (નેટવર્કિંગ, સિક્યોરિટી બેસિક્સ, લિનક્સ) એ પાયો છે જેના પર બાકીનું બધું નિર્ભર છે. હેકિંગ પર આગળ કૂદી ન જવું.
- **પ્રમાણપત્રો વૈકલ્પિક છે:** Network+ અને Security+ પ્લેલિસ્ટ તમને જરૂરી ખ્યાલો શીખવે છે. આ પ્લાનને અનુસરવા અથવા પ્રથમ નોકરી મેળવવા માટે તમારે પરીક્ષાઓ આપવી જરૂરી નથી.
- **તમારી પ્રગતિ ટ્રૅક કરો:** આ રિપોઝીટરીને ફોર્ક કરો (અથવા પ્લાનને નોટ્સ ફાઇલમાં કૉપિ કરો) અને જેમ જેમ તમે પૂર્ણ કરો તેમ દરેક દિવસ પર નિશાન કરો.
- **બધું મફત છે:** જો કોઈ સાાઇટ સામગ્રીને પેવૉલ પાછળ મૂકે, તો તે જ વિભાગમાં અથવા [`learn.md`](../../learn.md) માં સૂચિબદ્ધ વિકલ્પોનો ઉપયોગ કરો.
- **પ્રશ્નો અથવા અભ્યાસ મિત્રો:** [GitHub Discussions](https://github.com/farhanashrafdev/90DaysOfCyberSecurity/discussions) નો ઉપયોગ કરો. સમસ્યાઓ (Issues) તૂટેલી લિંક્સ અને સામગ્રી સુધારવા માટે છે.
- **કોઈ બીજી ભાષા પસંદ છે?** [Translations](../../README.md#translations) જુઓ.

### career-ops સાથે તમારી જોબ સર્ચ ચલાવો
[career-ops](https://github.com/career-ops-hq/career-ops) એ એક મફત, ઓપન-સોર્સ જોબ-સર્ચ સિસ્ટમ છે જે Claude Code, Codex, OpenCode, GitHub Copilot CLI અથવા Antigravity CLI જેવા AI કોડિંગ CLI ની અંદર ચાલે છે ([ફ્રી ટાયર](https://github.com/career-ops-hq/career-ops/blob/main/docs/FREE_TIER.md), કોઈ API કીની જરૂર નથી). કોઈપણ જોબ URL પેસ્ટ કરો અને તે તમારી `cv.md` સામે પોસ્ટિંગનું સ્કોરિંગ કરે છે (1-5), ATS-ફ્રેન્ડલી કસ્ટમાઇઝ્ડ PDF જનરેટ કરે છે અને એક જ જગ્યાએ દરેક અરજીને ટ્રેક કરે છે. તે ક્યારેય તમારા તરફથી અરજી કરતું નથી; તમે હંમેશા સમીક્ષા કરીને સબમિટ કરો છો.

કોઈપણ AI CLI નો ઉપયોગ કરતા પહેલા, `cv.md` માં સંવેદનશીલ વ્યક્તિગત ડેટા (ઉદાહરણ તરીકે સરનામું/ફોન નંબર) હાઇડ (redact) કરો અને તમારો રેઝ્યૂમે પેસ્ટ કરતા પહેલા ટૂલ/પ્રોવાઈડરની પ્રાઈવસી અને ડેટા-રિટેન્શન સેટિંગ્સની સમીક્ષા કરો.

1. **સેટઅપ (દિવસ 93):** [Node.js](https://nodejs.org) ઇન્સ્ટોલ કરો, [સેટઅપ ગાઇડ](https://github.com/career-ops-hq/career-ops/blob/main/docs/SETUP.md) પર નજર ફેરવો, પછી `npx @santifer/career-ops init` ચલાવો. સારી સુરક્ષા આદત: `npx` નવીનતમ રિલીઝ ડાઉનલોડ કરે છે અને ચલાવે છે, તેથી તેને ચલાવતા પહેલા [રિલીઝ નોટ્સ](https://github.com/career-ops-hq/career-ops/releases) તપાસો (જો તમને રિપ્રોડ્યુસિબલ ઇન્સ્ટોલ જોઈતું હોય તો `@santifer/career-ops@<version>` સાથે વર્ઝન પિન કરો). નવા `career-ops` ફોલ્ડરમાં તમારું AI CLI ખોલો અને ઓનબોર્ડિંગ ચેટને અનુસરો. તેને તમારી લક્ષિત ભૂમિકાઓ (ઉદાહરણ તરીકે *SOC analyst, security analyst, junior penetration tester*) જણાવો જેથી મૂલ્યાંકન એન્ટ્રી-લેવલ સુરક્ષા નોકરીઓ માટે યોગ્ય રહે.
2. **મૂલ્યાંકન (દિવસ 94):** Indeed અથવા LinkedIn પર તમને મળેલી 10-20 પોસ્ટિંગ્સ પેસ્ટ કરો. ફક્ત 4.0/5 કે તેથી વધુ સ્કોર ધરાવતી ભૂમિકાઓ માટે જ અરજી કરો; તેને ફિલ્ટર તરીકે ગણો, આડેધડ અરજી કરવાના સાધન તરીકે નહીં.
3. **અરજી કરો અને તૈયારી કરો (દિવસ 95):** તમારી શોર્ટલિસ્ટ માટે કસ્ટમાઇઝ્ડ CV જનરેટ કરો, અરજી કરો અને પ્રથમ કૉલ પહેલા તમારી STAR વાર્તાઓ બનાવવા માટે ઇન્ટરવ્યુ-પ્રૅપ મોડનો ઉપયોગ કરો.

## 🎉 યોગદાનકર્તાઓ (Contributors)

90DaysOfCyberSecurity સમુદાયનો ભાગ બનવા બદલ આભાર! અમારી સામગ્રીને સુધારવામાં મદદ કરનાર દરેક વ્યક્તિની અમે પ્રશંસા કરીએ છીએ.

### યોગદાનની શ્રેણીઓ:
- **દસ્તાવેજીકરણ (Documentation):** અભ્યાસ સામગ્રી અને માર્ગદર્શિકાઓમાં સુધારો કરો અથવા ઉમેરો.
- **ટ્યુટોરિયલ્સ અને માર્ગદર્શિકા (Tutorials & Guides):** જટિલ ખ્યાલો સમજાવતા ટ્યુટોરિયલ્સ બનાવો અથવા સુધારો.
- **સૂચિત સંસાધનો (Suggested Resources):** ઉપયોગી સાધનો, લેખો, પુસ્તકો અથવા અન્ય સંસાધનોની ભલામણ કરો.
- **વિચારો / વિષયો (Ideas / Topics):** શીખવાની સામગ્રીમાં ઉમેરવા માટે નવા વિષયો સૂચવો.
- **સમીક્ષા અને પ્રતિસાદ (Review & Feedback):** હાલની સામગ્રી પર પ્રતિસાદ આપો અને સુધારાઓ સૂચવો.
- **સમુદાય સહાય (Community Support):** ચર્ચાઓ અથવા સમસ્યાઓમાં પ્રશ્નોના જવાબ આપો અને અન્ય લોકોને મદદ કરો.
- **ટેસ્ટ અને ક્વિઝ (Tests & Quizzes):** શીખવાની પ્રગતિ તપાસવા માટે ક્વિઝ, પડકારો અથવા ટેસ્ટ ઉમેરો.
- **વાસ્તવિક દુનિયાની એપ્લિકેશનો (Real-World Applications):** સાયબર સુરક્ષા પ્રથાઓના વાસ્તવિક જીવનના ઉદાહરણો અથવા કેસ સ્ટડીઝ શેર કરો.
- **મેન્ટરિંગ (Mentoring):** અભ્યાસની સલાહ, ટિપ્સ અથવા અભ્યાસ સત્રોનું આયોજન કરીને અન્ય લોકોને મદદ કરો.

તમારા અદ્ભુત કાર્ય માટે તમામ યોગદાનકર્તાઓનો આભાર! 🎉
